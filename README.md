📊 Coca-Cola USA Sales Performance Dashboard (Excel)

---
🚀 Project Overview

This project presents a professional Excel Sales Performance Dashboard built using a structured KPI dataset. The dashboard provides actionable insights into revenue, profit, unit sales, regional performance, and brand-wise analysis for Coca-Cola USA operations.

The objective of this project is to demonstrate business-ready Excel dashboarding skills including PivotTables, slicers, KPI cards, map visualization, and dynamic image integration.

---

🎯 Business Objectives

Monitor overall sales performance

Track operating profit and margin trends

Identify top-performing retailers and beverage brands

Analyze regional and state-wise revenue distribution

Enable interactive filtering for business users

---

🧩 Dataset Features

The dataset includes the following key fields:

Retailer

Retailer ID

Invoice Date

Region

State

City

Beverage Brand

Price per Unit

Units Sold

Total Sales

Operating Profit

Operating Margin
